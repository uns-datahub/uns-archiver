# Contributing

Contributions are welcome through GitHub issues and pull requests.

1. Fork the repository and create a focused branch.
2. Install dependencies with `pnpm install`.
3. Make the smallest coherent change and add or update tests.
4. Run `pnpm run verify`.
5. Open a pull request describing the behavior change and verification performed.

Do not include credentials, deployment configurations, customer-specific topic
paths, generated live metadata, or runtime queue data.

By contributing, you agree that your contribution is licensed under the MIT
License.
